Fitur Unggulan

Dirancang untuk mempermudah tenaga kesehatan dan manajer program gizi.

📝

Pencatatan Digital

Input data balita, monitoring antropometri (TB/BB/Z-Score), dan pemberian PKMK dengan formulir terstandarisasi.

📊

Smart Analytics

Visualisasi Z-Score otomatis (BBU, TBU, BBTB), grafik pertumbuhan, dan dashboard compliance real-time.

🔔

Monitoring Kepatuhan

Pantau kepatuhan per minggu, konsumsi PKMK, dan identifikasi balita dengan red flag untuk intervensi cepat.

📦

Manajemen Logistik

Kelola stok PKMK per puskesmas, tracking distribusi, dan alert otomatis saat stok menipis atau habis.

📋

Rekap & Laporan

Generate rekap bulanan per puskesmas/desa, export Excel, dan dashboard agregat untuk pelaporan Dinkes.

📥

Import Excel

Upload data balita dan monitoring secara massal via template Excel dengan validasi otomatis dan Z-Score calculation.

Akses Kapan Saja via Mobile App

Aplikasi ini telah mendukung teknologi PWA (Progressive Web App). Anda dapat masuk langsung layaknya aplikasi native dari smartphone Anda, memanfaatkan akses fitur yang responsif.
